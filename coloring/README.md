# Ariel's Colors (Rabbit R1 creation)

A coloring book for a 2-year-old on the Rabbit R1. No reading, no menus, nothing to get stuck in.

- **Tap a shape** to fill it with the chosen color (with a little pop sound).
- **Drag a finger** to scribble with a crayon. The crayon stays inside the shape where the finger started, so scribbles always look tidy.
- **8 big color buttons** at the bottom. The selected one has a dark ring.
- **➡️** shows the next picture (sun, fish, house, flower, cat, car, balloons, butterfly, duck, ice cream). Each picture remembers its colors.
- **🧽** wipes the current picture clean.
- Color every shape and stars and confetti fall with a little tune.
- On the R1: the scroll wheel changes color and the side button shows the next picture.

Works offline once loaded. Sounds use the page's own audio, not the R1 voice.

## Install on the R1
1. On the R1: open the creations card → create → "add via QR code".
2. Scan `install-qr.png`.

The QR holds the JSON in `creation.json`.
